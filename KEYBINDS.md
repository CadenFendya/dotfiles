# Keybinds

All of these live in [`config/hypr/hyprland.lua`](config/hypr/hyprland.lua).
**Super** is the Windows key.

## Apps

| Keys | Action |
|---|---|
| Super + Enter | Terminal (foot) |
| Super + R | App launcher (rofi) |
| Super + Space | App launcher (rofi) |
| Super + B | Browser (firefox) |
| Super + E | File manager (dolphin) |
| Super + O | File manager (dolphin) |
| Alt + Z | Screenshot (flameshot) |

## Windows

| Keys | Action |
|---|---|
| Super + Q | Close window |
| Super + V | Toggle floating |
| Super + P | Toggle pseudo-tiling |
| Super + J | Flip split direction |
| Super + ← → ↑ ↓ | Move focus |
| Super + left-click drag | Move window |
| Super + right-click drag | Resize window |

## Workspaces

| Keys | Action |
|---|---|
| Super + 1–9, 0 | Go to workspace 1–10 |
| Super + Shift + 1–9, 0 | Send window to workspace 1–10 |
| Super + scroll | Next / previous workspace |
| 3-finger swipe left/right | Switch workspace (touchpad) |
| Super + S | Show / hide scratchpad |
| Super + Shift + S | Send window to scratchpad |

## Volume, brightness and media

| Keys | Action |
|---|---|
| Alt + ] | Volume up |
| Alt + [ | Volume down |
| Volume keys | Volume up / down / mute |
| Mic mute key | Mute microphone |
| Brightness keys | Brightness up / down |
| Play/Pause, Next, Previous keys | Media control (playerctl) |

## Session

| Keys | Action |
|---|---|
| Super + M | Log out of Hyprland |
